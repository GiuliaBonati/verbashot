# VerbaShot

**Capture. Report. Localize.**

VerbaShot is an open-source Chrome extension designed to simplify screenshot capture and visual evidence management during website localization QA.

## The Problem

Localization specialists and QA reviewers often need to capture screenshots, upload them to shared folders, and manually attach links to issue-tracking spreadsheets.

VerbaShot aims to streamline this workflow.

## Planned Features

- Capture screenshots of website issues.
- Organize screenshots automatically in project-specific Google Drive folders.
- Generate sequential filenames (`Screenshot_001.png`, `Screenshot_002.png`, etc.).
- Copy screenshot links to the clipboard.
- Insert screenshot links into Google Sheets.
- Manage multiple localization QA projects.

## Tech Stack

- JavaScript
- HTML & CSS
- Chrome Extensions Manifest V3
- Google Drive API
- Google Sheets API
- Google OAuth 2.0

## Project Status

**In development — initial setup**

The extension is not yet ready for production use.

## Privacy

VerbaShot is designed to handle screenshots securely. Project examples and screenshots published in this repository will use synthetic data only.
